# SmartCrow – Smart Scarecrow for Modern Farming 🌾⚙️

SmartCrow is a technology-enabled smart scarecrow designed to reduce crop damage caused by birds and animals using automation, motion detection, sound deterrence, ultrasonic repellent systems, and smart actuation.

Built as an agriculture-focused hardware project, SmartCrow combines traditional scarecrow concepts with embedded systems and IoT-inspired automation to create a practical, low-cost, and farmer-friendly field protection system.

## 🚀 Features

- Motion detection using PIR/IR sensors
- Automated arm movement using servo motors
- Loud alarm/audio deterrent system
- Solar-powered ultrasonic animal repeller
- Flashing light-based disturbance mechanism
- Dual-layer protection system
- Low-cost and retrofittable design
- Suitable for farms, gardens, and crop fields

## 🛠️ System Architecture

SmartCrow consists of two independent but simultaneous protection systems:

### 1. Main Robotic Scarecrow
- Detects nearby movement using sensors
- Activates motorized waving arms
- Plays loud deterrent sounds
- Controlled using ESP32 / Arduino-based logic

### 2. Solar Repellent Module
- Solar-powered standalone unit
- Emits ultrasonic frequencies
- Activates flashing lights during detection
- Works with minimal power consumption

## ⚡ Technologies & Components Used

- ESP32 / Arduino Uno
- PIR Motion Sensor
- Servo Motors
- Speaker Module
- Ultrasonic Repeller
- PVC-based mechanical frame
- Buck Converter
- Solar-powered protection module
